# Folhas

Um projeto pode ter **várias folhas**, como um conjunto de desenhos: a produção numa, a segurança noutra, o GEMMA noutra. Todas formam o mesmo automatismo.

## Utilização

- Os separadores estão por baixo da tela. **+** acrescenta uma folha; **duplo clique** no separador muda-lhe o nome.
- Para passar elementos para outra folha: selecione-os e, com clique direito, «Mover para …».
- Uma ligação entre folhas desenha-se como **referências**: uma seta «para a etapa 5 (Folha 2)» na origem e «de …» no destino. Continua a ser a mesma ligação.

## O que vê o projeto inteiro

A simulação, o ladder e Verificar trabalham com **todas as folhas** ao mesmo tempo. Ao exportar para PDF pode escolher «Todas as folhas».

> **Atenção:** os números de etapa devem ser únicos em todo o projeto, não só em cada folha.
